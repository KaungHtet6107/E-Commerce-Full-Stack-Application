📌 E-Commerce Full Stack Application
📖 Description
This project demonstrates a complete Java Full Stack E-Commerce system, including secure authentication, API development, payment integration, and cloud deployment. It is designed to simulate a real-world production environment using Docker and modern cloud services.
A full-stack E-Commerce Web Application built using modern technologies with a focus on scalability, security, and real-world deployment.
---
🚀 Tech Stack
🔹 Backend
Java 17
Spring Boot
Spring Framework
Spring Data JPA
Spring Security 7
JWT Authentication
REST API
PostgreSQL (v18)

🔹 Frontend
React (v19.2.4)
JavaScript
Vite
HTML / CSS

🔹 Payment Integration
Stripe API

 🔹 Tools & IDE
IntelliJ IDEA (Backend)
VS Code (Frontend)
---
☁️ Deployment
Backend: Docker + Render
Database: Neon (PostgreSQL)
Frontend: Netlify
---
🔐 Features
User Authentication & Authorization (JWT-based)
Role-based access control (Admin/User)
Product management (CRUD)
Cart and Order functionality
Secure payment integration with Stripe
RESTful API architecture
Responsive frontend UI
---
📦 Project Structure
Backend: Spring Boot REST API
Frontend: React SPA
Database: PostgreSQL
